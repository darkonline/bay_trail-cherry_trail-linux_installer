# Установщик Linux для планшетов на Intel Bay Trail / Cherry Trail

Программа для Windows, которая запускается **прямо на планшете** и готовит загрузочную флешку с
**postmarketOS v26.06 + Phosh** (сенсорная оболочка). Перед записью она проверяет железо планшета и говорит,
что заработает в Linux, а что потребует настройки.

> **Это прототип.** Проверено на одной модели — Digma CITI 1804 (Atom x5-Z8350, Cherry Trail).
> На других планшетах прогноз и подготовка флешки работают, но настройки под планшет после загрузки
> пока применяются только для Digma CITI 1804 (см. «После загрузки с флешки»).

## Что делает установщик

1. **Определяет планшет**: производителя, модель, процессор, разрядность UEFI.
2. **Прогноз — что заработает в Linux.** Сверяет устройства, которые видит Windows (тачскрин, звук, Wi-Fi,
   Bluetooth, датчик поворота, батарею, камеры), с драйверами ядра postmarketOS и с таблицами настроек под модели.
   По каждой детали пишет: «заработает», «скорее всего», «нужна настройка», «не заработает» или «неизвестно».
3. **Чего не хватает.** Для деталей, которым нужны файлы (прошивка тачскрина, настройки Wi-Fi, прошивка Bluetooth),
   предлагает взять их из драйверов Windows этого планшета, указать свой файл, папку или архив, выбрать похожую
   модель из списка — или пропустить.
4. **Скачивает образ** postmarketOS с официального сервера и проверяет его контрольную сумму (SHA-256).
5. **Записывает образ на флешку** и кладёт на неё папку `bt-installer` с выбранными настройками и найденными файлами.
6. По желанию **собирает архив с данными о планшете** для разработчиков (без серийных номеров).

В Windows установщик ничего не меняет. Флешка стирается только на последнем шаге, после трёх подтверждений.

## Что понадобится

- Планшет (или ноутбук) на **Intel Bay Trail или Cherry Trail** (Atom Z37xx, Z8300/Z8350/Z8500/Z8700 и др.) с работающей Windows.
- **Флешка от 8 ГБ.** Всё, что на ней есть, будет удалено.
- **7-Zip** — для распаковки образа: https://www.7-zip.org. На 32-битной Windows ставьте 32-битную версию (x86).
- **Интернет** и около **2 ГБ свободного места** на диске планшета (образ — 1,6 ГБ).
- Права администратора — Windows попросит разрешение только на запись флешки.

## Как пользоваться

1. Скачайте установщик: зелёная кнопка **«Code» → «Download ZIP»** вверху этой страницы.
2. Распакуйте архив в любую папку **на диске планшета** (не на ту флешку, которую будете записывать).
3. Запустите **`installer.bat`** (двойной щелчок). Если Windows покажет предупреждение SmartScreen —
   «Подробнее» → «Выполнить в любом случае».
4. Отвечайте на вопросы в окне. Номера пунктов вводятся цифрами, «да/нет» — буквами `д`/`н`.
5. На шаге «Запись на флешку» установщик покажет флешку и попросит ввести **номер диска** и слово **СТЕРЕТЬ**.
   Затем откроется отдельное окно с правами администратора, оно ещё раз спросит номер диска и запишет образ.
   Запись с проверкой занимает несколько минут.

## После загрузки с флешки

1. Вставьте флешку в планшет и включите его, открыв меню загрузки или настройки BIOS
   (клавиша зависит от модели: часто `F7`, `F12`, `Esc` или `Delete`). Выберите флешку — пункт с «UEFI» в названии.
2. Появится экран входа Phosh. Пароль пользователя образа по умолчанию — **`147147`**, смените его после входа
   командой `passwd`.
3. **Digma CITI 1804:** дальше — по инструкции
   https://github.com/darkonline/cherry-trail-linux_digma-citi-1804/blob/main/INSTALL.md (шаг 4 и далее):
   один скрипт применит все настройки тачскрина, звука, Bluetooth и сна.
4. **Другие планшеты:** система загрузится, но то, что в прогнозе отмечено «нужна настройка», пока придётся
   настраивать вручную. Выбранные настройки и найденные файлы лежат на загрузочном разделе флешки в папке
   `bt-installer` (`setup.conf`, `forecast.txt`, `touch/`, `firmware/`). Скрипт, который применяет их на планшете
   автоматически, — следующий этап разработки.

Установка на внутреннюю память (с удалением Windows) в установщик не входит.

## Помочь проекту

Если ваш планшет установщик не знает, в конце он предложит собрать архив: модель, плата и версия BIOS,
список устройств из Windows, прогноз, файлы, которые вы добавили. Серийные номера, UUID и имя компьютера
не собираются; архив можно открыть и проверить. Архив и файл `ПРОЧТИТЕ.txt` появятся в папке `Отправить-нам`
рядом с установщиком.

Отправить архив: создайте заявку в разделе [Issues](https://github.com/darkonline/bay_trail-cherry_trail-linux_installer/issues/new)
этого репозитория и перетащите zip-файл в поле описания. Установщик сам предложит открыть страницу новой заявки
с уже заполненным заголовком. Нужен бесплатный аккаунт GitHub. **Заявки и приложенные к ним файлы видны всем.**

## Откуда данные

- Драйверы и таблицы настроек под модели — исходники ядра Linux 6.18 и конфигурация ядра Alpine `linux-lts`.
- Прошивки тачскринов — [onitake/gsl-firmware](https://github.com/onitake/gsl-firmware), таблица `touchscreen_dmi.c`
  ядра и заводские пачки драйверов Digma (`catalog/local-fw`). Это файлы производителей тачскринов,
  распространяются, как и в gsl-firmware, для работы тачскрина в Linux на уже купленных устройствах.
- Положение датчиков поворота — `60-sensor.hwdb` из systemd.
